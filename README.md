# BigDongFootball league site

A static website that stitches the league's two homes into one continuous history:

| Era | Seasons | Source |
|---|---|---|
| ESPN | 2016–2021 | `espn/` (anonymized copy of the recovered ESPN archive; read-only) |
| Sleeper | 2022–present | `raw/sleeper/` (public Sleeper API, pulled by `tools/fetch_sleeper.py`) |

The eight Sleeper rosters are the same eight franchises that played on ESPN. `tools/identity_map.json`
links each Sleeper user to its ESPN manager id and each Sleeper roster to its ESPN team slot, so
careers, head-to-head records, streaks and the record book run across both platforms.

## Layout

```
site/
  tools/fetch_sleeper.py     pull league/users/rosters/matchups/brackets/drafts/transactions for the whole chain
  tools/build_site_data.py   merge ESPN + Sleeper into public/data/*.json
  tools/identity_map.json    the cross-platform identity map (edit if an owner changes)
  espn/                      anonymized ESPN archive (seasons, players, records) used as build input
  raw/sleeper/               raw Sleeper responses (regenerated by fetch; not committed)
  public/                    the website: index.html, app.js, styles.css, data/
  refresh.ps1                fetch + build in one step
```

## Deployment

`.github/workflows/deploy.yml` builds and publishes to GitHub Pages on every push to `main`,
on manual dispatch, and every Tuesday at 10:00 UTC so the site picks up the week's results
automatically. `public/data/` is generated in CI; the committed copy is only a local snapshot.

`public/` is the deployable artifact. It is plain HTML/CSS/JS with no build step; host it on
GitHub Pages, Netlify, Cloudflare Pages, or any static server. It must be served over HTTP
(the pages load `data/*.json` with `fetch`), so opening `index.html` from disk will not work.

## Refreshing during the season

```
powershell -File site/refresh.ps1
```

Fetch is unauthenticated and takes well under a minute. The newest league id is passed as the
argument; when Sleeper rolls the league into a new season, pass the new id (the previous one is
followed automatically through `previous_league_id`).

## Local preview

```
python -m http.server 8765 --directory site/public
```

then open http://localhost:8765.

## Privacy

Managers are labelled by their Sleeper usernames (already public on Sleeper) or, for the two
2016-only owners, by neutral labels. Real names, ESPN member ids and account aliases stay in
`../private/` and never enter `public/`. Historic team names and NFL player names are shown.

## Data notes surfaced on the site

- ESPN never returned transaction logs for 2016–2017; those seasons show "n/a" moves, not zero.
- ESPN lineups do not record starter/bench slots, so ESPN box scores list every rostered player.
- 2022 and 2023 exist on ESPN only as unused auto-renewed shells; the site uses the Sleeper seasons.
- Sleeper multi-week playoff games are shown as one game with per-week breakdowns; single-game
  records use one scoring week.
- Point totals are not normalized across the ESPN and Sleeper scoring systems.
